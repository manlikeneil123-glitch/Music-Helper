# Piano samples

Salamander Grand Piano V3 by Alexander Holm, licensed under
[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Converted from the
MP3 set published with Tone.js (tonejs.github.io/audio/salamander), then trimmed
to 3.5 s with a fade and re-encoded mono at 64 kbps for the app. One note every
three semitones from C2 to C7; the app pitches each to the nearest keys.
